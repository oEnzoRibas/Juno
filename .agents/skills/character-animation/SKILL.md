# character animation

Use a fixed canvas and registration point between poses. Place ear pivots at the skull, tail pivot at the rump and shoulder pivots under the chest. Extend hidden fur behind joints and test the intended rotation before exporting parts. Keep paired limbs and directional expressions explicitly named. Record parent, pivot, overlap and tested travel in the inventory. State which target application actually reopened the assets. Scope this workflow to preparation until rigging is explicitly requested.
