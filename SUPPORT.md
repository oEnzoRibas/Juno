# Support

Start with the documentation index. When enabled, use GitHub Discussions for setup questions, ideas, and community conversation. Use issue forms for bugs, feature requests, integrations, documentation, and architecture. Include the affected revision and enough context to understand the question. See the [community guide](docs/governance/community.md). During Phase 0, use your existing project contact for questions about the foundation.

Use [private security reporting](SECURITY.md) for vulnerability details and the [code of conduct](CODE_OF_CONDUCT.md) for conduct incidents. Keep personal data and credentials out of public discussions.
