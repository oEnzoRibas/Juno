# Logo usage guidelines

**Status:** The identity is approved. Placement and minimum sizes below are working guidance pending verification against the masters.

- Use the appropriate [lockup or symbol](../README.md) for the surface. Place a light wordmark on dark surfaces and a dark wordmark on light surfaces. On a busy background, use a solid contrasting container.
- Preserve proportions, rounded strokes, and geometry. Keep the intended symbol and wordmark relationship and use only approved treatments. Keep other content outside the surrounding clear space.
- Start with clear space on each side of at least one quarter of the rendered symbol height. Measure from visible artwork. Verify around the final lockup and in cramped layouts.
- Start with a full lockup width of 96 CSS px and a standalone symbol width of 24 CSS px. Measure the visible design and test at actual scale. Use the favicon-specific treatment in browser chrome. Confirm final minimum widths before release.
- For an identifying image without adjacent text, provide the accessible name “Juno”. For a linked home logo without visible text, use a name such as “Juno home”. Mark graphics decorative when nearby text already supplies the same accessible name.

See the [approved identity](../../../docs/design/brand-identity.md), [accessibility guidance](../../../docs/design/accessibility.md), and [proposed brand usage policy](../../../TRADEMARKS.md).
