# Mobile drawer, organization switcher and account concept

Proposal board for PR #37 review. It shows three 320 px navigation states in English and Brazilian Portuguese, using the approved light and dark color roles. These are views of one shell with separate interaction states. The drawer returns focus to the hamburger, the switcher displays tenant-scoped roles, and the account menu keeps language, theme and logout available.
