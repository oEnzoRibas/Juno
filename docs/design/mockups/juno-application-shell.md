# Juno application shell mockup

The editable comparison depicts the implemented desktop administrator dashboard in English and the narrow member dashboard in Brazilian Portuguese. The visual uses synthetic organization names. The expanded organization selector illustrates the same disclosure control on both screens. The working interface uses responsive dimensions and the operating system theme.

[Draw.io master](juno-application-shell.drawio), [SVG export](juno-application-shell.svg) and [PDF export](juno-application-shell.pdf)

The editable master separates surfaces, labels, controls, and the connector. It uses original Juno design tokens and a typographic wordmark to match the current implementation. See the [shell specification](../application-shell.md) and [ADR-0008](../../architecture/adr/0008-editable-diagrams.md).
