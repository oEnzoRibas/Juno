# Typography

**Status:** Geist and Inter are preferred candidates. Typeface selection remains open. Both upstream families provide SIL Open Font License 1.1 terms. If Juno bundles or self-hosts a font, pin the upstream version, preserve that release's notices and license, check any reserved names before modifying files, and document provenance. [Geist font license](https://github.com/vercel/geist-font/blob/main/OFL.txt) · [Inter font license](https://github.com/rsms/inter/blob/master/LICENSE.txt)

Compare both with the system sans-serif fallback using English and Brazilian Portuguese sample UI. Review diacritics, character distinction, body and status text, table numerals, long labels, zoom, and loading behavior. Begin with 1rem body type, approximately 1.5 line height, relative heading sizes, and an explicit fallback. Select a typeface after reviewing legibility and bundled size.
