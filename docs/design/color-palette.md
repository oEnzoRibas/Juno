# Official color palette

| Brand token | Approved hex |
| --- | --- |
| Primary | `#7565F5` |
| Accent | `#A99BFF` |

These values define the identity. Use [semantic design tokens](design-tokens.md) for surfaces, text, actions, and statuses. Primary on the light surface is approximately 3.98:1, below the 4.5:1 threshold for normal text. Validate text and controls in context across both themes. [WCAG 2.2 contrast criteria](https://www.w3.org/TR/WCAG22/#contrast-minimum)
