# Juno documentation

Phase 0 defines requirements and proposals. Published specifications use these statuses:

- **Implemented** means functionality exists and has recorded validation.
- **Planned** means a future capability or proposal.
- **Experimental** means an explicitly limited trial.
- **Deprecated** means previously available behavior with a documented migration or removal plan.
