## State and communication

The [existing protocol](../../PROTOCOL.md) defines task lifecycle. The scheduler's ready set is computed, so a node can be eligible while its persistent task record remains queued. Assignment publication, actual start, handoff publication, acknowledgement, independent qualification, maintainer acceptance and merge each need their own observable evidence. Use an explicit sender, recipient, task ID, base and artifact pin for messages. On receipt, verify the pin and return acknowledgement or a named blocker. Late or duplicate notifications resolve against the same task, pin and attempt. A newer pin creates a new review obligation.

The graph is a dependency relation, while the delegation tree records responsibility for a specific attempt. One independent review can depend on several branch heads and still have only one accountable reviewer. Parallel contracts may share read-only inputs. Mutable paths, ports, image tags, Compose projects, shared test databases and scarce desktop sessions need explicit reservation or serialization.

## Recovery and observability

Use the last verified checkpoint plus the current repository, assigned paths and remote head to resume after interruption or context compaction. Preserve uncommitted work and check for live processes before retrying. Reconstruct the packet at the original revisions. Record stale assumptions or missing artifacts before asking Agent 01 to reissue the contract. A summary from a model is a navigation aid. A receipt points to the command and artifact that can be checked.

Start with per-attempt local evidence and small sanitized event exports. Join on task, attempt, parent, revision and tool identifiers. Retain raw failures locally. Record event time only from an observed clock or source and model/effort only when exposed. Represent unavailable counts and costs as missing. A hook or protocol method listed by the CLI establishes availability at that surface. A native skill-load event requires a real event for that invocation. [Capability investigation](research.md).
