## Decision rule

Keep acceptance thresholds and the observation horizon in the evaluation protocol before trials. Report paired successes and failures, accepted results per elapsed hour, correctness, first-pass outcomes, human effort, coordination time and resource use. A missing token or spend reading stays unknown. For a topology comparison, hold model, effort, task revision, tool and permission availability, and rubric constant. Test skill, deterministic-gate and model effects in separate contrasts. Compare worker counts within the same workload family.

Do not recommend default adoption on the historical matched tie, a single fastest run or a successful synthetic grader check. A repeatable correctness regression, failure to recover verifiably, scope collision or unauthorized action blocks adoption of the affected path. Evidence for one workload should qualify only that workload until replicated. If the result is inconclusive, continue V1 and retain the experimental artifacts for a subsequent decision.
