## Improve the existing boundaries

Use the task workflow for orchestration, planning, context selection, recovery and feature handoffs. Put graph validation and context assembly in deterministic tools. Attach integration testing and code review to the review-environment and independent-review skills. Extend tenant-isolation or the existing threat model only when a reproducible defensive decision is missing. Instrument a measured performance regression first, then add its repeatable checks to the relevant owner workflow. Use the documentation skill for research-safe provenance and links; keep private rubrics in Research. Treat evaluation, routing metadata lint and skill-version comparisons as tooling. Add a new skill only after repeated cases reveal a distinct trigger that a focused extension cannot address.

For each affected skill, capture source SHA, file name, metadata, required tools and one held-out adjacent negative. Validate frontmatter and relative references at the actual PR pin. In fresh sessions test (1) discovery for this cwd, (2) explicit structured invocation, (3) an unprompted matching request plus an adjacent negative, and (4) behavior against the expected artifact and a deterministic or independent reviewer. A natural-language mention alone is an ambiguous activation signal. Record unknown activation separately from a wrong answer. Compare old and new revisions against the same public case and a private held-out case. Preserve the old outcome and require owner review for any policy or skill change.
