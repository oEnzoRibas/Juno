Living reference pages without an identified publication date are marked undated. Case studies inform candidate designs. Transport and schema documentation describe interfaces. ## Interpretation

Juno's historical corrective signal is a false confidence problem at review boundaries. A required named SQL fixture was absent from a passing runner, and a browser UAT had a different source tree. An independent human discovered the mismatch. A gate should verify actual fixture execution and runtime identity before a handoff can claim coverage. Preserve observed exit codes and missing evidence as separate fields. [PR #40 correction](../../history/JUNO-0042-pr-40-runtime-review.md).

Architecture comparisons are hypotheses about coordination under those constraints. Tooling and team composition change together in uncontrolled project history. Record first-pass correctness, total elapsed time through independent qualification, reviewer effort and rejected outputs, then compare matched interventions with the same revision and budget.
