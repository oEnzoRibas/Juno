## Scope

Implement scoped, time-limited invitations, account activation, secure sessions, revocation and global identity to membership mapping.

## Resumption condition

Approved self-hostable identity and session approach.

## Acceptance and validation

Reject replay, expired invites, unauthorized invitations and cross-organization token use. Validate local login with no provider integrations.

Record applicable approved ADRs, affected files, migrations or API contracts, security, accessibility and localization considerations, and actual test results at implementation. See the [Phase 1 plan](../phase-1-implementation-plan.md) for review and validation gates.
