# JUNO-0037 — Maintainer acceptance preview

Owner-authorized integration and documentation task. This task does not occupy a frontend, platform or core implementation reservation.

The preview must provide a local browser entry point, a scope limited to published and validated candidate work, a private PostgreSQL service, synthetic test accounts, a private credential mechanism, repeatable validation, a maintainer runbook and an explicit update and reset policy.

The first environment is left running for the maintainer. The local preview and its data stay in place while the documentation awaits review. See the [preview record](../history/JUNO-0037-uat-preview.md) and [permanent protocol](../maintainer-uat.md).

The maintainer accepted the running preview. The [acceptance record](../history/JUNO-0037-maintainer-acceptance.md) records the owner decision and the verified integration.
