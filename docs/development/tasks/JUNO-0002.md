## Original request and implemented scope

See the [owner brief](../history/JUNO-0002-request.md). Accepted Docker and Compose as project requirements. Documented development, lifecycle, networks, secrets, Dockerfiles, CI, independent deployment and recovery. Service choices are proposals.

Recreated all six references as Draw.io masters with individually editable nodes, connectors, labels, boundaries and vector stencils. Exported and verified six SVG and six PDF copies. Preserved the twelve original diagram exports byte for byte in [references](../../architecture/diagrams/references/README.md). Converted FIFO sample IDs to illustrative names, improved small-label contrast, and kept the layouts. Documented the [visual standard](../visual-documentation.md).

Inventoried the supplier logo kit and preserved the updated standalone symbol variants that arrived during this task. Created a transparent favicon and application icon from approved paths. Embedded the logo and system view in README.

## Validation and limitations

- Verified the official Draw.io Desktop 32.7.4 portable archive SHA-256. Exported both formats from all six masters. Verified native cells, vector shapes, original canvases, selectable attribution, link targets, and unchanged reference hashes. Rendered each SVG and all six PDF pages and visually inspected the resulting sheets using Poppler and PyMuPDF.
- Initial SVG export showed oversized canvases on two views. Constrained the offending label bounds and regenerated and reviewed all exports. Initial inline icon images had inconsistent SVG viewer support. Replaced them with native vector stencils.
- Verified that the eight concurrently updated symbol SVG/PDF files and four new PNGs exist with square canvases and that the transparent variants retain alpha. Checked both derived icons at 16, 24 and 32 px.
- Docker and Compose CLI reported Engine 29.9.3 and Compose 5.7.0 on this machine. No images, containers, runtime tests, CI runs, migrations or API changes apply in the documentation-only task. No platform support is claimed.
- Application deployment, identity, runtime service layout, telemetry, registry and operating targets remain implementation decisions. Repository promotion and scoped PRs belong to [JUNO-0003](JUNO-0003.md).
