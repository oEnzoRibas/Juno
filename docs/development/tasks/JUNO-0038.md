# JUNO-0038 — Independent self-hosted distribution

| Field             | Value                                                                                                                                                  |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Requested         | 2026-11-24 by the project owner                                                                                                                        |
| Status            | IN_PROGRESS                                                                                                                                            |
| Dependencies      | [ADR 0005](../../architecture/adr/0005-mandatory-containerization.md), [JUNO-0020](JUNO-0020.md), [JUNO-0022](JUNO-0022.md), [JUNO-0024](JUNO-0024.md) |
| Approved decision | [ADR 0012](../../architecture/adr/0012-self-hosted-distribution.md)                                                                                    |

Publish the independent distribution contract and deliver an operator installation from versioned source. Reuse the current identity, migration, readiness and tenant provisioning path. Validate secure cookies over HTTPS, instance-specific bootstrap, one- and two-tenant operation, persistence, backup and restore, and versioned updates. Release artifacts, supported platform and resource matrix, and runtime-only image packaging require independent validation and human publication approval.

The [deployment handoff](../agents/agent-01/handoffs/juno-self-hosted-distribution.md) records exact dependencies and reservations. This independent task can proceed while organization membership policy waits for its own approval.
