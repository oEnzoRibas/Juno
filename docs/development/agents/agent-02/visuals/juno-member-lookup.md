# Member lookup and details

Implemented for JUNO-0028. The editable [Draw.io master](juno-member-lookup.drawio) and synchronized [SVG](juno-member-lookup.svg) and [PDF](juno-member-lookup.pdf) show the directory filters in a desktop layout and the detail in a mobile layout. Both use synthetic memberships and the existing Juno design tokens. The mockup uses English light and Brazilian Portuguese dark to illustrate both locales and themes.

The email is an ordinary link with a visible focus indicator. Role and active status have text labels. Clearing or applying a filter starts at the first page. Links to details, the previous context and the alternate locale preserve the current filter and cursor.

See the [implementation handoff](../handoffs/JUNO-0028-member-lookup-ui.md) and [tenant branding guidelines](../../../../design/tenant-branding.md).
