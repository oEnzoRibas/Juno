# Tenant member directory

This editable mockup illustrates the implemented member directory in a desktop light theme and a narrow dark theme. All names and addresses represent synthetic fixtures.

[Draw.io master](juno-member-directory.drawio) · [SVG export](juno-member-directory.svg) · [PDF export](juno-member-directory.pdf)

The reference compresses spacing and uses one example row. The implemented table retains all four semantic columns inside a keyboard-focusable horizontal scroll region on narrow screens. Pagination appears only when the API supplies a next cursor or the address already contains a cursor. Browser captures use test-generated data served by the real API.
