# Organization profile interface

Implemented for JUNO-0028. The [editable Draw.io source](juno-organization-profile-ui.drawio), [SVG](juno-organization-profile-ui.svg) and [PDF](juno-organization-profile-ui.pdf) show the saved state in Brazilian Portuguese on desktop and the edit form in English on a narrow dark layout. The examples use synthetic organization names and a decorative accent.

Input labels, the format hint, visible focus, and success and error announcements use the existing accessible form primitives. The organization accent changes the decorative border. Form controls retain the Juno design tokens in both themes.

See the [implementation handoff](../handoffs/JUNO-0028-organization-profile-ui.md) and [tenant branding guidelines](../../../../design/tenant-branding.md).
