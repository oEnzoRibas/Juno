# Containerized development and deployment

**Status:** Partially implemented. **Last meaningful update:** 2026-11-24.

The Compose starter runs Next.js, the Nest API, PostgreSQL and a one-shot migration. It uses private database networking, health checks, a project-scoped volume and loopback application ports. Worker jobs, object storage and a production deployment profile remain planned. GitHub Actions publication is pending workflow permission.
