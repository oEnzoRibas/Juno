# Integration ecosystem

**Status:** Proposed. **Last meaningful update:** 2026-11-24.

Juno's independent core and central Hub connect to optional provider categories via reviewed community adapters.

Each tenant chooses which providers to enable. Provider availability and scopes remain planned.
