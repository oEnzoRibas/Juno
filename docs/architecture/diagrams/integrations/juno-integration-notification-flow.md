# Integration notification flow

**Status:** Proposed. **Last meaningful update:** 2026-11-24.

A committed event can produce an internal notification independently of any optional delivery configured by a tenant.

Authorized destinations, redaction and deduplication protect external delivery. Provider failure does not reverse the core transaction.
