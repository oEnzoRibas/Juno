# Integration adapter architecture

**Status:** Proposed. **Last meaningful update:** 2026-11-24.

Domain use cases use capability contracts, a registry and reviewed external adapters. Example capabilities are notifications, documents and project sync.

Core domains have no provider SDK dependencies. Interface choices and approval remain pending.
