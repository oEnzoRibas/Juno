# Multi-agent development architecture

**Status** Accepted development workflow, 2026-11-24.

The project maintainer controls architecture decisions and merge approval. Agent 01 coordinates the central queue and core engineering, Agent 02 owns product design and frontend, and Agent 03 owns platform engineering and independent quality validation. Each agent works in a separate task branch and worktree. All three record implementation, checks and handoffs before review. This diagram describes how Juno is developed.
