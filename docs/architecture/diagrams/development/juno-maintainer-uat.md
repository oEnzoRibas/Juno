# Maintainer acceptance preview

The local preview pins published candidate commits and runs in its own worktree and Compose project. The maintainer reaches the web and API over loopback. PostgreSQL stays on an internal network and persists across ordinary shutdown. Agent sessions retain their own task worktrees and environments.
