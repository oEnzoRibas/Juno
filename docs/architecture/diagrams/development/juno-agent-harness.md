# Agent harness and temporary specialists

- [Editable Draw.io master](juno-agent-harness.drawio)
- [Vector SVG](juno-agent-harness.svg)
- [Print PDF](juno-agent-harness.pdf)

The maintainer authorizes scope and accepts the reviewed result. The registry assigns exact ownership to the three persistent lanes. Reusable skills guide any lane, and temporary specialists return scoped patches or evidence. Agent 03 independently verifies other lanes through the existing exact-revision review tooling. Research preserves the inputs and observations of the separate evaluation.

The initial exports share the geometry and labels of the editable master. The SVG includes the source SHA-256. Chromium printed that SVG to the PDF. For subsequent Draw.io edits, regenerate the SVG and PDF with the [repository exporter](../../../../scripts/diagrams/README.md) and visually inspect both outputs.
