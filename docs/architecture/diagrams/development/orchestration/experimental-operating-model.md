# Directorates pilot operating model

Status: approved experimental design. Revised 26 November 2026. Product reference 550bab236d069689c6894c490bf698e945d57749. FR-01 / JUNO-0028. Original project creator: Enzo Ribas. Developed with AI assistance.

Agent 00 owns event-driven dispatch and integration and contributes orchestration receipts to operational evidence intake. Core, Product and Platform contribute their own receipts to the same intake. The independent Researcher receives those records, evaluates them against research-controlled ground truth and returns recommendations to Agent 00 along a separate path. The maintainer retains scope and protected decisions. Assigned sessions and temporary workers are distinct from logical roles; research has no reserved worker slot.

Renderer: SVG generated as native vector shapes, text and routed arrows from the same semantic source as the editable Draw.io master. PyMuPDF 2.1 converted the SVG to the vector PDF. The Juno diagram checker's master and export checks were run on this bundle before handoff. Draw.io Desktop was not used to render these exports.

This diagram represents governance for the approved pilot. It does not certify live dispatch, recovery, product acceptance or merge.
