# Gamification event flow

**Status:** Proposed. **Last meaningful update:** 2026-11-24.

Proposed internal learning, report, and challenge events plus optional verified provider contributions. Tenant rules award recognition with provenance. A post-commit path may emit optional external notifications.

Rewards use tenant-scoped, auditable idempotency. Scoring and notification delivery failure rules require implementation tests.
