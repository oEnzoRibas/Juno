# Independent self-hosted distribution

[ADR 0012](../adr/0012-self-hosted-distribution.md) defines the separation between upstream software distribution and operator-owned installations. The two operator models share the same tenant-aware architecture. Each operator has independent persistence and backups. See the [deployment guide](../../deployment/README.md).
